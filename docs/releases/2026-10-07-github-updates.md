# 时光屋 1.2.17 · 私有 GitHub 更新

将完整项目迁移至私有仓库 `charlotteamian/TimeHouse`，保留原始图稿、历史复核证据和未完成批次。原本 build 下有追溯价值的文本记录归档至 `docs/archive/build-records/`。

设置页增加“应用更新”：配置私有仓库只读访问令牌、检查新版、显示下载进度、取消下载、校验安装包并打开 Android 系统安装界面。令牌使用 Android Keystore 的 AES-GCM 加密，独立于健身数据备份；使用私有 Release 的固定 `latest-build` 入口和最后发布的 `update.json`。

下载采用流式写入，校验大小、SHA-256、包名、版本号与当前应用签名。仅向这个仓库的 GitHub API 发送访问令牌；APK CDN 重定向不携带令牌。安装权限由系统处理，安装需要用户在系统界面确认。网络、权限、发布中的版本和校验失败会显示可重试说明。

GitHub Actions 自动检查资料、动画、语音与复核指纹，构建 APK 并更新私有 Release；每次构建自动增加版本号。沿用原有签名，覆盖安装保留应用记录。

中文动作名“V字”的数据校验误报已修正，未修改动作资料或授予新复核状态。云端检查不代替逐项人工动作复核或实体手机测试。
