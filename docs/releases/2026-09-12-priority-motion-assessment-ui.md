# 时光屋 1.2.3 · 721 条动作图、评估管理与训练体验修复

## 动作图

- 严格限定自重、弹力带、哑铃、壶铃、TRX 悬挂带、瑜伽球、BOSU 球、动感单车。
- 716 张新四阶段源图 + 5 个完全重复动作复用，覆盖 721 条范围内动作；另有 4 条上游器械错标记录在排除清单中。
- 721 个 App 动画均通过 480×480、四帧、时长、完整性与导入映射检查；自动复核条目均已逐张人工放行。

## 体能评估与强度

- 设置页新增体能评估管理卡：查看 / 修改、重新评估、删除。
- 新版评估保存原始安全筛查答案，修改时可还原；旧记录明确提示无法还原原答案，不虚构勾选状态。
- 删除或重做评估后立即重建相关计划并清除未开始的旧训练草稿，避免继续引用旧评估日期或强度上限。
- 手动强度仍优先于默认值；真实伤痛或安全筛查阳性时才进行可解释的安全降级。

## 推荐、界面与自定义动作

- 推荐先按蹲 / 髋 / 推 / 拉 / 核心等动作模式编排，再在相同模式内轮换最近完成或刚推荐的动作；轮换是软降权，候选不足时可以复用。
- 安排说明公开动作模式、器械、恢复、周训练量、时长求解与轮换逻辑。
- 今日时间按钮保持单行；动作组编辑、排序和删除按钮增加横向与纵向间距。
- 自定义动作支持选择和再次修改主要器械，保存后重启仍保留。
- 从相册选择的图片 / GIF 会复制到 App 私有目录；旧版失效地址改为明确提示重新选择，不再当作网页链接打开。

- 全部领域、数据集、1324 个动画、菜谱、语音和快捷饮食检查通过。
