# 解剖动作帧出图规格（给 GPT 用）

这份规格是给图像模型（GPT-4o 图像 / DALL·E 等）看的，让它产出的**起始帧 + 结束帧**能直接被
`scripts/animate_anatomical_frames.py` 用光流补成 App 里的循环动图。核心要求只有一条：
**两帧必须是同一个人、同一机位、同一光照、同一比例，只有身体姿势不同。** 这样光流才能
把像素平滑地从起始位挪到结束位，不糊、不变脸、前后统一。

---

## 一、出图格式（二选一）

- **方式 A（推荐，单图两格）**：一张横图，**左格 = 起始姿势，右格 = 结束姿势**，两格之间不留缝、
  不加分隔线。整图尺寸 ≥ 1536×768（每格 ≥ 768×768）。
  - 之后用：`python3 scripts/animate_anatomical_frames.py sheet <图>.png 0 <输出>.gif`
- **方式 B（两张独立图）**：`{动作}_start.png` 和 `{动作}_end.png`，各 ≥ 768×768。
  - 之后用 manifest 批量喂给动画器。

> 想一张大图放多个动作也行：按 **2 列（起始|结束）× N 行（每行一个动作）** 排版，
> 动画器 `--row` 逐行取。现有 8 张 sheet 就是 2×3 的排法。

---

## 二、画风（对齐现有 24 张原始图）

- **纯白背景 `#FFFFFF`**，无地面阴影、无网格、无边框、无文字/水印/标注/箭头。
- **一个肌肉发达的男性 3D 解剖模型**：中性灰白皮肤 + 清晰肌肉分块（écorché/解剖图鉴感），
  不是照片、不是写实健美照、不是卡通线条。
- **只把该动作的目标肌群染成红色**（例如卧推=胸大肌+三头，深蹲=股四头+臀），其余保持灰白。
  红色要贴在**正确的肌肉解剖位置**上，不要染到衣服/袜子/皮肤大片。
- 下装：**纯黑短裤**；鞋可有可无但两帧一致。
- 相关**器械照实画**（杠铃/哑铃/长凳/拉力器/单杠等），同样是灰黑金属质感，两帧位置一致。

---

## 三、一致性（最关键，决定动图糊不糊）

同一个动作的起始 / 结束两帧，必须**逐项对齐**：

| 必须相同 | 只能不同 |
|---|---|
| 人物身材、肤色、发型、面朝方向 | 关节角度 / 身体姿势（起始 ↔ 结束） |
| 相机机位、视角、焦距、缩放 | 目标肌群的收缩状态（可略微更红） |
| 光照方向与强度 | 器械随动作移动的位置（如杠铃上下） |
| 人物在画面里的**中心位置和大小** | |

- 起始 = 动作的**伸展/预备位**；结束 = **收缩/顶峰位**（例：弯举=手臂放下 → 手臂举起）。
- 幅度别太夸张：两帧姿势差**中等**即可，差太大光流会拉扯变形。
- 全身入镜（或该动作相关的大部分身体），四周留约 10% 余白，两帧留白一致。

---

## 四、给每个动作提供的信息

出图时附带：动作**英文名 + 中文名 + 目标肌群**。例如：

```
Exercise: dumbbell biceps curl / 哑铃弯举
Target (paint red): biceps
Equipment: one dumbbell per hand
Start: arms extended down at sides, dumbbells held
End: forearms curled up to shoulders
View: side (3/4)
```

---

## 五、我这边怎么接

你把图给我后，按动作 ID 命名（`dataset_motion_<id>` 或 `motion_<key>`），我用
`animate_anatomical_frames.py` 批量处理：先做**全局配准**（把结束帧的整体平移/缩放
拉回起始帧的几何），再按配准质量二选一——
- 两帧真正对齐（edge_align ≥ 0.62 且静态区残余 ≤ 2px）：10 帧 2.36 秒循环，
  保持帧是原图，过渡帧只重绘运动部件（快闪 70ms，读作动态模糊）；
- 对不齐（场景被重画/视角变了）：干净的两帧翻页（1180ms×2），绝不扭曲器械。

归一到 480×480 白底，写进 `app/src/main/res/raw/`（WebP）和
`build/anatomy-motion-gifs/`（同帧 GIF 预览），跑 `validate_exercise_gifs.py` 校验。
翻页里对不齐最严重的会记进 `build/anatomy_redraw_candidates.json` —— 重画这些行
（同机位、同比例、同位置，只改姿势）就能升级成平滑版。
